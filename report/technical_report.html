Predicting Campus Facility Energy Consumption

NTU Datathon 2026 · Track 1: Smart Campus Analytics  |  Team kkboys  |  Regression · 8,000 train / 3,000 test · evaluated by RMSE

1. The problem, and what makes it hard

We predict energy_usage for a campus building from its identity, time, weather, occupancy and its preceding reading. The headline difficulty is not finding signal — previous_usage alone correlates 0.945 with the target, and simply copying it forward scores RMSE 6.40. The difficulty is that the test set is systematically harder than the training set, in a way that silently corrupts how a team measures its own progress.

2. Two findings that shaped everything

(a) This is not a time series, despite looking like one. With hour, month, a lag feature and a tidy ID split, a time-aware split is the natural response. We tested rather than inherited that: there is no timestamp, so ordering is undefined; every ID–feature correlation falls within ±0.016; and an ID-ordered holdout scored 3.606 against 3.560 for random 5-fold — inside the ±0.071 fold noise. We use random K-fold, keeping 20% more training data than a time split would allow.

(b) Standard validation is ~11% optimistic here. Every gap-prone feature is missing 4–5× more often in test than in train. 18.2% of test rows carry at least one gap versus 5.8% of training rows; for rows with two or more gaps the split is 7.7% versus 0.14% — a 55× difference. A model validated on training-like data is therefore graded on an easier problem than it will face. We measured the bias directly: one fitted model, same validation rows, scored 3.560 as-is and 3.960 once the fold was degraded to test-level missingness.

The consequence is worse than an inflated number. Models degrade at different rates, so naive validation can misrank them. On our own earlier candidates, a Ridge model appeared 0.20 RMSE better than gradient boosting and was actually 0.08 worse under test conditions. All model selection in this work is therefore made on RMSE with test-level missingness injected into every validation fold, fixed before any model was tuned. We then tightened the protocol once more: test gaps are clustered (81.8% of rows have none, 10.5% one, 6.9% two, 0.8% three) rather than independent per column, so independent injection under-represents two-gap rows about 3×. Validation and training augmentation both now reproduce the test's gap-count mix, which moved our production model from 3.20 to an honest 3.34 without changing the model at all.

3. Approach

Features. Exploration showed buildings differ in shape, not merely in level: mean usage spans 30.8 (Administration) to 79.2 (Science), while variability ranges from sd 6.5 (Residential, highly regular) to 19.1 (Lecture Halls, volatile). We encode this explicitly — per-building intercept, 24-hour profile, weekend offset, and per-building slopes on occupancy, temperature and previous usage (370 features, including temperature × time-of-day terms for cooling load) — plus cyclical hour encoding and per-column missingness indicators.

Imputation. This proved the single most valuable decision. A median is not merely imprecise: the building slopes are products is_building × value, so one missing input collapses the entire building-specific relationship for that row. We instead train a dedicated LightGBM per gap-prone column, predicting it from building, hour and the remaining drivers, then regenerate the interaction terms. The v2 imputer passes co-missing predictors to LightGBM as NaN instead of a fake median (3.338 → 3.291; rows missing occupancy and usage fell from 7.45 to 6.38 RMSE). Crucially the imputer predicts features from features — the target is never involved — so it can legitimately be fitted on the training and test features together, giving it 11,000 rows instead of 8,000 and direct exposure to the distribution it must impute into. Augmentation. Training contains roughly 11 multi-gap rows against ~231 in test, so the model has almost no exposure to the regime it is graded on. Degrading the training data to test-level missingness improved every model tested (CatBoost by 0.265) and halved fold variance. This uses only the observed missingness rate of the test features — no test labels are involved.

4. Model selection

A regularised linear model on explicit building interactions beat every gradient-boosted model standalone, because the structure is close to additive: a building's base level, its own daily profile, and near-linear responses to its drivers. On complete rows Ridge scores 3.04 against 3.35 for LightGBM. For v2 we blend Ridge with an MLP and a native-NaN LightGBM, because they make different errors. The weights are fixed NNLS values (0.66 / 0.22 / 0.12), fitted on one CV repeat and scored on another, so the gain is held-out rather than self-graded. Rows missing previous_usage get their own weights, leaning ~48% on a Ridge trained without that feature: when the strongest input is absent, a model that never relied on it beats imputing it.

Reweighting our out-of-fold errors to the test file's composition gives 3.34, matching the public score. The test oversamples extreme scenarios about 5× (heatwave afternoons, occupancy surges, sudden usage drops), and these carry the extra error. The public subset's own noise (sd ≥ 0.08) is larger than the gaps between our candidates, so we did not tune against it.

6. Error analysis

Residuals are centred and symmetric, with no bias across the prediction range. Error tracks each building's intrinsic volatility: Lecture Halls hardest, Residential easiest. Much is irreducible, but it means a campus-wide average understates uncertainty on exactly the buildings an operator would most want warning about. Error rises with missing-input count: two-gap rows score about 4.7 RMSE against 3.3 overall, and heatwave afternoons about 6.2.

7. Covariate shift: detected, and deliberately not corrected

A classifier trained to separate training rows from test rows reaches AUC 0.688 — the two sets are distinguishable. This is not an artefact of the missingness: removing the missingness indicators leaves the AUC unchanged (0.689), and restricting to complete cases, where no gaps exist at all, still gives 0.654. The shift is in the feature values themselves (test rows are busier and carry higher previous usage).

We applied the textbook correction — importance weighting by the train/test propensity ratio — in four variants. Every one made the model worse (3.28–3.51 vs 3.23 unweighted). Covariate shift only induces bias when the model is misspecified: if P(energy | features) is stable, reweighting removes no bias and adds variance, exactly the pattern observed. The physics of a building does not change because the sample contains busier ones. We report the shift as a measured property and deliberately leave it uncorrected.

8. Limitations and next steps

  • No timestamps, so genuine lag or rolling features are impossible; previous_usage is the only history available.
  • Imputation error is invisible downstream. Missingness flags let the model discount estimated values; propagating imputation uncertainty would be the principled fix.
  • Augmentation rates are calibrated to the public test set. If the private set is harsher they are slightly off, though this should still degrade more gracefully than median-based alternatives.
  • High-variance buildings dominate residual error. Per-building or mixed-effects models are the next step, alongside a cost-weighted error view — a 5-unit error on a 30-unit admin block matters more proportionally than on an 80-unit science building.
  • The floor is close. Complete rows alone score 3.04, residuals show no group effects by building, month or hour, and the learning curve flattens near 4,500 rows. We estimate the noise floor on this feature set at about 3, so large further gains would need information the dataset does not contain.
  • Dozens of variations were tested; few were kept. Rejected on evidence: log and delta target framings, extra interaction families, splines, residual boosting, target encoding, per-building models, specialist routing for gap rows, imputer tuning, pseudo-labelling and importance weighting. We read this as a sign the remaining error is largely irreducible — with previous_usage at r = 0.945 there is limited signal left to extract.
